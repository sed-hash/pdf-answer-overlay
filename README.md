# 講義資料 PDF解答自動合成プロジェクト

講義スライド等のPDFから、白マスクで隠された解答テキストを抽出し、元のレイアウトを保ったまま赤字でオーバーレイ合成するツール群です。

## 構成ファイル

- **`app.py`**: Webアプリ（Streamlit）本体。ブラウザ上でドラッグ＆ドロップしてPDFを合成・ダウンロードできます。
- **`Webアプリ起動.bat`**: ダブルクリックするだけでブラウザ上のWebアプリを立ち上げるバッチファイル。
- **`requirements.txt`**: Webアプリの動作に必要なPythonパッケージ一覧（Streamlit Cloudデプロイ時にも使用）。
- **`pdf_overlay_tool.py`**: `PDF解答合成ツール.exe` の元ソースコード。
- **`delete_original_tool.py`**: `未解答の元資料削除ツール.exe` の元ソースコード。
- **`PDF解答合成ツール.exe`**: Windows用スタンドアロン実行ファイル（フォルダ内一括処理／ドラッグ＆ドロップ対応）。
- **`未解答の元資料削除ツール.exe`**: 解答入りPDFが存在する元資料を安全にごみ箱へ移動するツール。

## 今後の作業・拡張
Antigravity（またはVS Code）でこのフォルダ（`I:\マイドライブ\PDF解答合成ツール`）を開くことで、いつでも機能追加やWebアプリの改良を継続できます。
